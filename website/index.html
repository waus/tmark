01 / Why

Structure travels. Presentation doesn’t.

HTML and DOCX mix content with presentation. Markdown is fragmented, hard to extend and short on built-in types. tmark keeps the document structure; rendering stays with the app.

01

Explicit structure

Headings, lists, media, maps and other elements stay explicit.

02

Renderer-owned presentation

Web, mobile, bots and exports each use their own native styles.

03

Small, strict surface

Strict parsing and limited extensions keep documents portable.

03 / Format surface

Document primitives, not a layout system.

{h;} {p;}

Text structure

Headings, paragraphs, quotes, details and dividers.

{list;} {table;}

Collections

Lists, tasks, tables, cells and nested content.

{img;} {video;}

Media

Images, video, audio, slideshows and collages.

{a;} {ref;}

Connections

Links, anchors, references, icons and dates.

{b;} {i;} {m;}

Inline meaning

Emphasis, marks, spoilers, code and math.

{map;}

Rich blocks

Maps, attached media and application-native embeds.
